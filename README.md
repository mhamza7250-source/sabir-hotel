# Sabir Hotel & Restaurant — Vehari

Online menu and WhatsApp ordering website for **Sabir Hotel & Restaurant**, Peer Murad, Multan Road, Vehari (Near COMSATS University).

## Features
- 79 menu items in 9 separate menus (Biryani & Rice, Desi Chicken Karahi, Chicken Karahi, Beef Karahi, Mutton Karahi, BBQ, Special Salan, Naan Roti, Drinks/Chai/Dessert)
- Every item has its own dish photo, with Half / Full / Quarter options
- Order on the website first (cart + order form + live order preview), then the complete order is sent as a properly formatted text to the hotel's WhatsApp
- Popular items row, item badges, Google Maps directions, print/save menu
